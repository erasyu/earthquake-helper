# Earthquake Helper

Приложение для отслеживания землетрясений и обеспечения безопасности при сейсмической активности.

## Основные функции:

### Мониторинг землетрясений
- Отслеживание землетрясений в Казахстане и по всему миру
- Реальновременные уведомления о новых землетрясений
- Фильтрация по магнитуде и временному периоду

### Информация о землетрясениях
- Детальная информация о каждом событии (магнитуда, глубина, время)
- Визуальное отображение на карте с анимированными маркерами
- Доступ к официальным источникам через кнопку "Подробнее"

### Зоны эвакуации
- Информация о безопасных зонах в крупных городах Казахстана
- Навигация до ближайших зон эвакуации
- Визуализация зон эвакуации на карте

### Дополнительные функции
- Рекомендации по безопасности
- Контакты экстренных служб
- Руководство по оказанию первой помощи

## Особенности реализации

### Фильтрация землетрясений по Казахстану
Приложение автоматически фильтрует землетрясения по региону Казахстана:
- Основные границы: 40.9° - 55.4° широты, 46.5° - 87.4° долготы
- Специальные зоны для крупных городов (Алматы, Астана, Шымкент)

### Retry логика
При ошибках сети автоматически выполняются повторные попытки:
- Максимум 3 попытки
- Экспоненциальная задержка между попытками
- Таймаут 10 секунд на запрос

### Кэширование
- Режим реального времени: кэш на 5 минут
- Обычный режим: кэш на 30 минут
- Автоматическое обновление при истечении срока

## API и источники данных

### USGS API
- **URL**: `https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson`
- **Формат**: GeoJSON
- **Использование**: Основной источник данных о землетрясениях по всему миру
- **Обновление**: Каждые 5 минут для режима реального времени

### EMSC API
- **URL**: `https://www.seismicportal.eu/fdsnws/event/1/query`
- **Формат**: JSON
- **Использование**: Альтернативный источник данных, особенно для Европы и Азии
- **Обновление**: Каждые 5 минут для режима реального времени

### Retry логика
- **Максимум попыток**: 3
- **Экспоненциальная задержка**: 2, 4, 6 секунд
- **Таймаут запроса**: 10 секунд
- **Обработка ошибок**: Автоматический fallback на кэшированные данные

## Кэширование данных

### Режим реального времени
- **Время кэша**: 5 минут
- **Ключ кэша**: `earthquakes_realtime`
- **Автоматическое обновление**: При истечении срока кэша

### Обычный режим
- **Время кэша**: 30 минут
- **Ключ кэша**: `earthquakes_{period}` (day, week, month)
- **Автоматическое обновление**: При истечении срока кэша

## Фильтрация землетрясений

### По Казахстану
Приложение автоматически фильтрует землетрясения по региону Казахстана:
- **Основные границы**: 
  - Широта: 40.9° - 55.4°
  - Долгота: 46.5° - 87.4°
- **Специальные зоны**:
  - Алматы: радиус ~200 км
  - Астана: радиус ~150 км
  - Шымкент: радиус ~150 км

### По магнитуде
- **Минимальная магнитуда**: Настраивается пользователем
- **По умолчанию**: 0.0 (все землетрясения)

### По времени
- **Период**: 1, 7, 30 дней
- **Режим реального времени**: Последний час

## Уведомления

### Условия отправки
- **Магнитуда**: >= 4.0 (настраивается)
- **Местоположение**: В пределах Казахстана
- **Интервал**: Не чаще одного раза в 5 минут

### Типы уведомлений
- **Push-уведомления**: Через Firebase Cloud Messaging
- **Локальные уведомления**: Для значительных землетрясений
- **Фоновые обновления**: Периодическая проверка новых землетрясений
